# llm-chat-app-langchain
A simple LLM-powered question-answering web application built using LangChain, Streamlit, and Ollama.
The app allows users to ask questions through a web interface and get responses from a Large Language Model (LLM).

This project is designed to demonstrate core GenAI concepts such as prompt templates, LLM chaining, output parsing, and environment configuration.

🚀 Features

💬 Interactive chat-style question answering

🔗 LangChain pipeline using LCEL (prompt | llm | output parser)

🤖 Supports local LLMs via Ollama (Gemma model)

🧪 LangSmith tracing support (optional)

🌐 Simple and clean UI using Streamlit

🔐 Secure configuration using environment variables

🛠️ Tech Stack

Python

LangChain

Streamlit

Ollama

Gemma LLM

python-dotenv

LangSmith (optional for tracing)
